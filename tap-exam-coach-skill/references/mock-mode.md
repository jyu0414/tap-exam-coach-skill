# 模試モード

目的は、実力を測ることと本番の時間感覚に慣れること。学習モードとは分けて、**途中で正誤も解説も出さない**。出題の形（UI、問題文のルール、正解位置）は `references/question-rules.md` に従う。

## 1. 構成

| 項目 | 決め方 | CISSPの例 |
|---|---|---|
| 問題数 | 本番と同じ。長すぎる場合は縮小版も選べる | 本番100〜150問。フル125問、縮小版50問 |
| 分野配分 | 公式の出題比率で按分（端数は比率の大きい分野から丸める） | D1 16 / D2 10 / D3 13 / D4 13 / D5 13 / D6 12 / D7 13 / D8 10 (%) |
| 時間 | 本番の制限時間（縮小版は問題数で按分） | 最大3時間（縮小版50問なら72分） |
| 小項目 | 分野内で偏らないよう散らす。学習モードで出した問題の使い回しは避ける | |
| 正解位置 | 全選択肢に均等。おすすめ印のルールは学習モードと同じ | |
| 問題文 | question-rules.md 4章をすべて守る | |
| 形式 | 本番の出題形式どおり（`formats.md`）。短答・大問がある試験は本番と同じ割合で入れる | |
| 画面に出す情報 | 本番の試験画面で開示されるものだけ（`exam-profile.md` の出題形式）。本番が残り時間と問題番号だけなら、それだけを出す | CISSPは分野名を出さない |

縮小版50問の分野配分（CISSP比率の例）: D1 8 / D2 5 / D3 7 / D4 6 / D5 7 / D6 6 / D7 6 / D8 5。合計が問題数になることを必ず確かめる。

## 2. 開始前

1. 問題数・制限時間・ルール（途中で正誤を出さない、戻れる/戻れない）を示し、フル版か縮小版かを選んでもらう
2. 「開始」の合図をもらってから始める。開始時刻を記録する（Claude Code なら `date`）
3. 全問の正解と分野・小項目を、出題前に `mock-results.md` の作業欄（または `mock-N-answers.md`）に書いておく。採点と中断再開のため

## 3. 進め方

1. 1問ずつ出題し、回答したら確定。返すのは「回答を記録しました」と次の問題だけ。正誤・解説・励ましの言葉で正誤が分かる表現（「さすがです」など）も出さない
2. 回答は出題ごとにファイルへ追記する（会話が切れても再開できるように）
3. Claude Code の AskUserQuestion は1回に最大4問まで並べられる。模試は途中で解説しないので、利用者が速く進めたいなら4問ずつまとめて出してよい（最初に「1問ずつ／4問ずつ」を選んでもらう）。見出しは「問13/50」のように各問に付ける
4. 前の問題に戻れない試験（CATなど）なら見直しなし。戻れる試験なら最後に見直しを許す（見直したい問題番号を聞き、その問題だけ再提示する）
5. 中断したら、何問目まで進んだか・経過時間を記録し、`progress.md` に「模試N 問X/Y で中断」と書く。再開時はそこから続け、中断中の時間は所要時間に含めない
6. 終了時刻を記録し、所要時間と1問あたりの平均時間を出す

### 長さへの対処

100問を超えると会話が長くなる。回答はその都度ファイルに書き、会話の中で過去の問題を振り返らなくても採点できるようにしておく。会話が要約されても、ファイルの正解表と回答表で採点できる。

## 4. 採点と結果

最後にまとめて出し、`mock-results.md` に書く。

まず本番で結果として開示される形（合否のみ、分野別の評価など）で一度示し、そのあと練習用に詳しい内訳を出す。本番での見え方を知っておくため。

- 総合の正答数と正答率
- 分野別の正答率（表）
- 合否の目安: 合格基準と比べて「合格圏 / ボーダー / 要補強」。CATやスケールスコアの試験では正答率と合否が一対一ではないので、**「目安」であることを明記する**
- 所要時間と1問あたりの平均、時間配分の評価（本番の制限時間に対して時間切れの恐れがあるか）
- 誤答の一覧（問題番号、分野、自分の回答、正解）
- 「誤答だけ1問ずつ解説しますか」と聞き、希望すれば学習モードの解説の型で解説する。誤答は弱点ノートに記録する（`references/review.md`）
- 判断点の模試なら、`plan.md` に書いた基準と比べ、受験日の見直しを提案する（setup.md 4章）。基準未満なら後ろ倒し案を示し、決めるのは利用者

合否目安の区分（試験の合格基準を P% 相当としたとき）:
- 合格圏: P+5ポイント以上
- ボーダー: P−5〜P+5ポイント
- 要補強: P−5ポイント未満

CISSPなら合格基準700/1000を概ね70%相当として扱い、その旨を明記する。
