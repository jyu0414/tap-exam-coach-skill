# W3 弱点ノート（科目B演習: ネットワーク攻撃）
## シナリオ（問1〜4共通）
A社はDMZにキャッシュDNSサーバを置き、インターネットからの再帰問い合わせを受け付けていた。ある日、外部のB社から「A社のDNSサーバから大量のDNS応答が届いている」と連絡があった。

```
(インターネット)──[FW]──[DMZ: DNSサーバ]
      │
   [B社のサーバ]
```
## 進行表
- 問1: 9.1 DNS / オープンリゾルバの意味 / 模範「外部からの再帰問い合わせに応答するDNSサーバ」/ 正解
- 問2: 9.1 DNS / FWで確認すべきログの送信元ポート / 模範「53」/ 正解
- 問3: 9.2 DoS / 「B社に大量の応答が届いた仕組みを40字以内で述べよ」/ 模範解答「送信元IPアドレスをB社に偽装した問い合わせにより、増幅した応答をB社に送らせた」/ 採点基準: 必須①送信元IPアドレスをB社（攻撃対象）に偽装 ②応答（増幅されたもの）がB社に送られる。別解「リフレクション（反射）攻撃で応答をB社に向けた」は②を満たす。40字超過は不可 /
